# Релиз цикла (cycle-N → main)

Редкий процесс, вынесен из CLAUDE.md. Делай по порядку, ничего не пропуская.

## Предусловия
1. Все пункты текущего `docs/cycles/cycle-N.md` — в статусе `готово` либо `отложено`/`отклонено` с причиной.
2. Локально зелёные: `./gradlew testDebugUnitTest assembleDebug`.
3. CI на последнем коммите `cycle-N` зелёный: `gh run list --branch cycle-N --limit 1`, при сомнении `gh run view --log-failed`.

Если что-то красное — сначала чини (не ослабляя тесты), только потом слияние.

## Слияние
1. Убедись, что `cycle-N` запушена и CI на ней зелёный.
2. `git checkout main && git pull`.
3. `git merge cycle-N` (merge, не rebase — история циклов сохраняется). Конфликтов быть не должно, если `cycle-N` создана от свежего `main`; возникли — разреши аккуратно, не теряя чужие правки.
4. `git push` в `main`.
5. **Дождись зелёной сборки на `main`** (`build.yml`): `gh run list --branch main --limit 1`. Красная — чини и пушь, пока не зелёная.

## После слияния
- Артефакт APK (`bank-aggregator`) берётся из зелёной сборки `main`.
- Файл цикла `docs/cycles/cycle-N.md` остаётся в `docs/cycles/` как архив; в `docs/ROADMAP.md` статусы пунктов меняются на «сделано». Новый цикл заводит `cycle-start` (ветка `cycle-(N+1)` от `main`).

## Подпись
Подписью/keystore не занимайся. Переход на ключ публикации — отдельно, только по `docs/publishing.md` и решению пользователя.
