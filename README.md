# Агрегатор счетов

Личное Android-приложение: собирает балансы и операции по счетам из push-уведомлений
банков и показывает общий капитал — счета, вклады, валюту и наличные — и кэшбэк.
Все данные хранятся на телефоне.

Банки: Сбербанк, Т-Банк, Альфа-Банк, Яндекс Пэй, МТС Деньги, Ozon Банк,
Альфа-Бизнес, Т-Бизнес, BSB Bank.

## Что умеет

- **Обзор** — общий капитал из четырёх частей с полосой состава; что входит в итог,
  выбирается в шторке ⚙. Умная плашка кэшбэка на месяц.
- **Кэшбэк** — по банкам и по категориям, распознавание скринов (Tesseract, офлайн),
  виджет на рабочий стол.
- **Капитал** — счета по банкам, вклады (начисления по дням и месяцам, завершённые),
  валюта (история покупок и продаж наличной валюты, средняя цена, прирост по курсу ЦБ,
  валюта на счетах) и наличные рубли.
- **Настройки** — банки, резервная копия в «Загрузки/BankAggregator», журнал перехвата.

## Архитектура

DDD, три слоя, зависимости внутрь: `ui → domain ← data`.
- `domain` — модели и чистая логика (деньги, вклады, валюта, капитал, кэшбэк), интерфейсы
  репозиториев, use-cases. Без Android, покрыт JVM-тестами.
- `data` — Room, репозитории, настройки, бэкап, курсы ЦБ.
- `ui` — Jetpack Compose, Material 3, дизайн-система «Слиток» (одна тёмная тема).

Подробности — в `CLAUDE.md`.

## Приватность и сеть

- Только уведомления, без чтения SMS. Пакеты банков объявлены в `<queries>`,
  без QUERY_ALL_PACKAGES.
- В сеть приложение ходит только за публичными курсами ЦБ РФ (`XML_daily.asp`).
  Данные пользователя никуда не отправляются. Без сети всё работает, кроме обновления курса.

## Сборка

APK собирается в GitHub Actions при пуше в `main`
(**Actions** → последний запуск → артефакт `bank-aggregator-debug`).
Локально: `./gradlew testDebugUnitTest assembleDebug` →
`app/build/outputs/apk/debug/app-debug.apk`.

Серверный код в `server/` — опциональный артефакт на будущее, в приложение не входит.
Идеи и дорожная карта — в `docs/ROADMAP.md`, ТЗ текущего цикла — в `docs/TZ.md`, прошлые циклы — в `docs/archive/`.
