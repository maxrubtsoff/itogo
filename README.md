# Itogo

Личное Android-приложение (бывший «Агрегатор счетов»): собирает балансы и операции
по счетам из push-уведомлений банков и показывает общий капитал — счета, вклады,
валюту и наличные — вместе с кэшбэком и подписками. Все данные хранятся на телефоне,
база зашифрована. Вход — пин или отпечаток.

Банки: Сбербанк, Т-Банк, Альфа-Банк, Яндекс Пэй, МТС Деньги, Ozon Банк,
Альфа-Бизнес, Т-Бизнес, BSB Bank. Список расширяется по мере задач.

## Что умеет

- **Обзор** — общий капитал одной суммой и полосой состава. В герое — переключатель
  «По частям · По банкам»: разрез по частям (счета, вклады, валюта, наличные) или
  по банкам (сумма в каждом банке с автоцветом по логотипу). Умная плашка кэшбэка
  на месяц.
- **Капитал** — счета по банкам, вклады (начисления по дням и месяцам, завершённые),
  валюта (история покупок и продаж наличной валюты, средняя цена, прирост по курсу
  ЦБ, валюта на счетах) и наличные рубли.
- **Платежи** — кэшбэк (по банкам и по категориям, распознавание скринов на
  Tesseract, офлайн, виджет на рабочий стол) и подписки (оплаты, напоминания). Из
  карточки банка — фильтр по этому банку.
- **Настройки** — банки, резервная копия в «Загрузки/BankAggregator», журнал
  перехвата, пин и отпечаток.

## Архитектура

DDD, три слоя, зависимости внутрь: `ui → domain ← data`.
- `domain` — модели и чистая логика (деньги, вклады, валюта, капитал, кэшбэк,
  подписки, разрез по банкам), интерфейсы репозиториев, use-cases. Без Android,
  покрыт JVM-тестами.
- `data` — Room (SQLCipher), репозитории, настройки, бэкап, курсы ЦБ, OCR,
  эмбеддер.
- `ui` — Jetpack Compose, Material 3, дизайн-система «Слиток» (одна тёмная тема),
  цифры одним шрифтом (Unbounded для отдельных значений, Golos — в фразах).

Подробности — в `CLAUDE.md`.

## Приватность и сеть

- Только уведомления, без чтения SMS. Пакеты банков объявлены в `<queries>`, без
  `QUERY_ALL_PACKAGES`.
- В сеть приложение ходит только за публичными курсами ЦБ РФ (`XML_daily.asp`).
  Данные пользователя никуда не отправляются. Без сети всё работает, кроме
  обновления курса.
- База SQLCipher, ключ в Android Keystore. Копия шифрованная, с паролем. Вход —
  пин или отпечаток.
- Политика конфиденциальности — `docs/privacy.md`.

## Сборка

Release APK и AAB собираются в GitHub Actions при пуше в `main` и `cycle-*`
(**Actions** → последний запуск → артефакты `bank-aggregator` для APK и `itogo-aab`
для AAB). Release подписан ключом публикации из секретов CI; до их настройки —
фиксированным `app/debug.keystore` из репозитория. Локально:
`./gradlew testDebugUnitTest assembleDebug` →
`app/build/outputs/apk/debug/app-debug.apk`. Текущий `versionName` — `1.0.0`,
`versionCode` = номер сборки CI.

Выкладка в RuStore и чеклист — в `docs/publishing.md`.

Серверный код в `server/` — опциональный артефакт на будущее, в приложение не
входит. Идеи и дорожная карта — в `docs/ROADMAP.md`, файл текущего цикла — в
`docs/cycles/cycle-N.md`, прошлые циклы — там же.
