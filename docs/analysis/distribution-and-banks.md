# Разбор: распространение, свой набор банков, выбор разделов

2026-10-22. Ответ на вопросы Максима: как отдать приложение людям, если у каждого свои банки; как определять банки; выбор разделов; банки, которых нет на телефоне; поиск логотипов.

## 1. Как сейчас устроены банки

- Список банков задан в коде: `domain/model/BankBrand.kt` — перечисление из 9 банков (Сбер, Т-Банк, Альфа, Яндекс Пэй, МТС Деньги, Ozon, Альфа-Бизнес, Т-Бизнес, **BSB Bank**) + «Другой банк». У каждого — название, цвет, пакеты приложения, валюта по умолчанию (у BSB — без неё: «руб.» там белорусский).
- Те же пакеты перечислены в `AndroidManifest.xml` в `<queries>`. Это нужно Android 11+: без `<queries>` приложение не видит чужие приложения (не может проверить, установлены ли они, и взять иконку). Широкое разрешение `QUERY_ALL_PACKAGES` мы сознательно не берём (`CLAUDE.md`, приватность).
- «Установлен ли банк» — `util/InstalledApps`: для каждого пакета из списка спрашиваем систему `getPackageInfo`. Иконка — `getApplicationIcon` (с цикла 3 — кэш на диске).
- Перехват — `service/BankNotificationListener`: получаем **все** уведомления телефона, но записываем только от выбранных пакетов из списка.
- Разбор текста (`domain/parser/NotificationParser`) от банка **не зависит** — ищет сумму, валюту, баланс по общим шаблонам. Значит, неизвестный банк с похожим текстом уведомлений, скорее всего, разберётся и сейчас — его просто не пускает фильтр.
- В базе банк хранится строкой `brandKey` (вклады, кэшбэк, события, скрины). Это хорошо: пользовательские банки можно хранить с ключом вида `user:…` без смены схемы этих таблиц.
- Личное, что «зашито»: только BSB Bank в каталоге (как обычный банк, без данных счетов) и тексты «Максим/Казань» в `CLAUDE.md`. Данных пользователя в коде нет.

## 2. Можно ли находить банковские приложения на телефоне автоматически

| Способ | Работает? | Почему |
|---|---|---|
| Перечислить все приложения и отобрать «финансы» | Нет (без `QUERY_ALL_PACKAGES`) | Android 11+ скрывает чужие приложения. Категория приложения (`ApplicationInfo.category`) не имеет значения «финансы». `QUERY_ALL_PACKAGES` в Google Play требует обоснования и противоречит нашему принципу приватности |
| `<queries>` по интент-фильтру «банк» | Нет | Такого общего интента у банков нет |
| **По уведомлениям** | **Да** | Слушатель уведомлений уже получает уведомления **от всех** приложений с именем пакета. Если от приложения пришло уведомление, похожее на денежное (парсер нашёл сумму и ₽/$/€ или «Баланс/Доступно»), — это кандидат в банки |

**Предложение (F-23): «Нашли новый банк».** Слушатель не отбрасывает молча уведомления от незнакомых приложений: если текст разбирается как операция, пакет попадает в «кандидаты» (сам текст **не сохраняется**, только пакет, время и что это похоже на операцию). В «Банках» появляется плашка «Похоже на банк: <имя приложения> — собирать?» — одно касание, и банк в списке, следующие уведомления записываются.
- Имя и иконку незнакомого приложения взять сложнее: оно не в `<queries>`, и система может их не отдать. Что точно есть у уведомления: пакет, маленькая иконка уведомления (`smallIcon`), заголовок. Нужно проверить на телефоне, отдаёт ли система подпись и иконку приложения, от которого пришло уведомление; если нет — пользователь задаёт название и логотип сам (см. справочник ниже), подставляем цвет и первую букву.

## 3. Выбор разделов (F-21)

**Что:** при первом запуске и в «Настройках» — экран «Что храним»: плашки как у частей капитала: **Счета** (из уведомлений), **Вклады**, **Валюта**, **Наличные**, **Кэшбэк**. Выключенный раздел исчезает везде:
- Счета выключены → нет запроса доступа к уведомлениям, нет «Банков» для перехвата, нет журнала, нет «Счетов» на Обзоре и в «Капитале», слушатель ничего не записывает.
- Кэшбэк выключен → нет вкладки «Кэшбэк», плашки на Обзоре, виджета (виджет показывает «Кэшбэк выключен»).
- Вклады / Валюта / Наличные выключены → нет раздела в «Капитале», строки на Обзоре, части в общем капитале.
- Всё, кроме Кэшбэка, выключено → вкладки «Капитал» нет; всё выключить нельзя (последняя плашка не гаснет — как в F-12).
- Это **не то же**, что «входит в общий капитал» (F-12): там раздел виден, но не суммируется; здесь раздела нет вовсе. На экране «Что храним» и в шторке капитала — одна и та же сетка плашек, но разный смысл; в шторке капитала показываются только включённые разделы.
- Данные выключенного раздела не удаляются — включил обратно, всё на месте.

## 4. Банки, которых нет на телефоне, и свой справочник (F-22)

Проблема: вклад в банке, приложения которого нет (или банк не из списка) — сейчас это «Другой банк» с фиолетовой буквой.

**Предложение: справочник банков = встроенные + свои.**
- Встроенные (как сейчас) — заготовки: название, цвет, пакеты, валюта. Пользователь не правит, но может скрыть.
- Свои: «+ Банк» — название (обязательно), цвет (подбирается сам из логотипа), логотип (необязательно), приложение-источник уведомлений (необязательно: выбирается из «кандидатов» F-23), валюта по умолчанию.
- Везде, где выбирается банк (вклад, кэшбэк, скрин), — общий выбор из справочника с поиском и «+ Банк» в конце списка.
- Распознавание скринов: название банка со скрина сопоставляется и со своими банками (по названию).
- Технически: `BankBrand` (enum) заменяется моделью `Bank(key, title, color, logo?, packages, currency, builtIn)`; встроенные остаются с прежними ключами (`sber`, `bsb`…), свои — `user:<uuid>`; Room — таблица `banks` для своих; бэкап их выгружает. Затрагивает ~48 файлов, где используется `BankBrand`, — самый крупный пункт; делается отдельным этапом, с тестами на миграцию ключей.

## 5. Логотип: искать в интернете или нет

| Вариант | Плюсы | Минусы |
|---|---|---|
| Поиск картинок Google | Удобно | Нарушает принцип «в сеть только за курсом ЦБ»; официальный API платный и требует ключа; выдача картинок без API — против правил Google и ломается; качество непредсказуемо (не тот логотип, водяные знаки) |
| Иконка сайта банка (`https://сайт/apple-touch-icon.png`, favicon) по введённому адресу | Бесплатно, обычно чистый квадратный логотип 180 px | Сетевой запрос — в банк уходит сам факт запроса с IP; нужно явное «Найти логотип на сайте» по кнопке, не автоматически |
| **Иконка приложения банка**, если оно установлено | Уже есть, офлайн | Только для установленных |
| **Из галереи/скрина** + обрезка в круг + убрать фон на телефоне | Офлайн, бесплатно, любой банк | Пользователю нужен скрин/картинка с логотипом |
| Буква + фирменный цвет (как сейчас) | Всегда работает | Не логотип |

Удаление фона на телефоне: простой и офлайн-способ — фон определяется по цвету краёв картинки и делается прозрачным (логотипы обычно на однотонном фоне); плюс обрезка по содержимому и вписывание в круг. Google ML Kit «subject segmentation» качественнее, но тянет Google Play Services и скачивание модели — против «офлайн и без чужих сервисов».

**Решено (2026-10-22):** в сеть за логотипом не ходим. Справочник банков ЦБ (в приложении, без сети) + ручной ввод; логотип — иконка приложения, своя картинка или до 3 букв с выбранными цветами фона и букв (F-22). Публикация и ключ — в идеях (I-10).

**Рекомендация (была):** по порядку — иконка установленного приложения → картинка из галереи/скрина с автообрезкой и снятием однотонного фона → буква с цветом. Поиск в интернете — только как явная кнопка «Найти на сайте банка» (favicon по адресу сайта) и только если ты согласен отступить от правила «сеть только для ЦБ»; Google-поиск не делать.

## 6. Как распространять

| Канал | Что нужно | Замечания |
|---|---|---|
| **GitHub Releases** (открытый репозиторий) | Релиз с APK на каждый тег; люди ставят и обновляются через Obtainium/вручную | Проще всего; без проверок магазина |
| **RuStore** | Аккаунт разработчика, политика конфиденциальности, описание доступа к уведомлениям | Основной магазин для РФ; Google Play в РФ ограничен |
| F-Droid | Только открытый код, сборка их сервером из исходников, без закрытых зависимостей | ONNX/Tesseract — открытые, но сборка нативных библиотек может не пройти их правила; дольше всего |
| Google Play | Аккаунт $25, декларация доступа к уведомлениям, политика данных | Для РФ малоприменимо; слушатель уведомлений допускается при явном объяснении |

**Обязательно до публикации:**
1. **Свой секретный ключ подписи.** Сейчас APK подписан `app/debug.keystore`, который лежит в репозитории. Пока приложение личное — нормально. В открытом репозитории любой может подписать этим ключом своё APK, и оно встанет поверх настоящего как «обновление» — с доступом ко всем уведомлениям. Нужен новый ключ, хранится только в секретах GitHub Actions; **смена ключа = один раз удалить и поставить заново** (данные — через резервную копию).
2. Отвязать личное: убрать из `CLAUDE.md` имя/город (или оставить — это не данные), BSB Bank оставить встроенным (не мешает), а можно скрыть по умолчанию.
3. Первый запуск: выбор разделов (F-21) → если выбраны счета — объяснение и запрос доступа к уведомлениям → выбор банков (найденные на телефоне — сразу включены).
4. Политика конфиденциальности (одна страница: всё на телефоне, в сеть — только курсы ЦБ).
5. Версии: `versionCode`/`versionName` растут с каждым релизом (сейчас стоят 1 / 0.1.0), сборка релиза по тегу.
6. Лицензия репозитория (например, MIT или GPL).

## 7. Порядок работ (предложение)

1. F-21 «Что храним» — независимо, сразу полезно.
2. F-22 справочник банков (+ логотип из галереи с обрезкой) — самый большой, отдельным этапом.
3. F-23 кандидаты из уведомлений — после справочника (кандидат превращается в свой банк).
4. U-20 подготовка к публикации (ключ, версии, релизы по тегу, политика) — последним, перед первым публичным релизом.
