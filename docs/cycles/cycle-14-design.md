## B-108

**Макет:** https://claude.ai/artifact/S4wbzaNpQcMBcmo7MSn7Ah (исходник `docs/mockups/cycle-14/b108-chart-labels.html` + `mock.css`). Вкладки «Сейчас · А · Б · В · Г», в каждой латунь «Всё», фиолет «Вклады», тесный случай (две сделки подряд у верхнего края, небо «Валюта»), ниже та же подпись на четырёх цветах.

### Почему две правки не помогли
1. **Буквы полые (вероятная главная причина).** `CapitalChart.kt:180–181` рисует один `TextLayoutResult` дважды: сначала `drawStyle = Stroke(0.75.dp)`, потом без `drawStyle`. У `DrawScope.drawText(textLayoutResult, …)` `drawStyle = null` значит «как у макета текста», а кисть макета после первого вызова осталась обводкой. Второй проход — ещё один контур цвета `Muted`, заливки нет. На скрине b-108 «+1,3 млн ₽» как раз контурная. Правки цвета и прозрачности это не задевали. Проверить на device-check: поставить `drawStyle = Fill` во втором вызове — буквы станут сплошными.
2. **Тихий цвет.** `Muted` 11 sp на заливке 18 % и свечении героя даёт около 4,5:1 — на грани даже залитым.
3. **Ореол не набирается.** Обводка 0,75 dp наружу выходит на ≈0,4 dp. Толще 2 dp — у 11 sp слипаются просветы букв.
4. На скрине b-109 («Всё») подписей нет, потому что герой свёрнут в полосу (U-67), а там они выключены по правилу. Это не ошибка.

## U-69

**Макет:** https://claude.ai/artifact/EG3c8KmkssaKPgo7diibE5 (исходник `docs/mockups/cycle-14/u69-account-pick.html` + `mock.css`). Вкладки: «Шторка и выбор» (сейчас → «Изменить» → шторка «Банк» → обратно), «Состояния строки», «Если счетов у банка станет несколько» (на будущее).

### Решение: новый компонент не нужен
- Счёт в Itogo — это `банк:валюта` (`RecordNotification.kt:69`, `RepairFromJournal.kt:127`), а шторка правки берёт только счета в валюте операции (`HistoryOperations.kt:98`). Значит, в этом списке у каждого банка ровно один счёт, и выбор банка однозначно даёт счёт. Случая «несколько счетов у одного банка» в этой шторке сейчас нет.
- Поэтому вместо нового `AccountPickSheet` расширяем канон: `BankPickSheet(selected, onPick, onDismiss, onClear = null, banks: List<BankBrand>? = null)`. Если `banks` передан, показываются только эти банки (вместо `pickable(LocalMyBanks.current, selected)`), остальное как есть: заголовок «Банк», поиск от 6, `SheetRow` с `BankIcon(36)`, галочка `Brass2`, закрытие после выбора.
- Строка — готовый `SelectRow`; подпись поля — «Банк» (совпадает с заголовком шторки), а не «Счёт».
- На будущее (не в этом цикле): если счёт станет «банк + маска» (B-107 маску уже читает, но в `accountId` она не идёт), понадобится `AccountPickSheet` со строкой `SheetRow(title = банк, subtitle = "счёт *4863 · 48 210,00 ₽")`. Различать маской и остатком, по названию нельзя. Вид — на третьей вкладке макета.

- `ui/history/OperationSheet.kt:191–198`: вместо `Text("Счёт")` + колонки `SlitokChip` → подпись «Банк» (тем же стилем, что «Сумма» у `AmountField`) + `SelectRow(value = acc?.title, placeholder = "Выберите банк", onClick = { pickingBank = true }, leading = acc?.let { { BankIcon(it.brand, 36.dp) } })`, где `acc = d.accounts.firstOrNull { it.id == accountId }`; `if (pickingBank) BankPickSheet(acc?.brand, onPick = { b -> accountId = d.accounts.first { it.brand.key == b.key }.id }, onDismiss = { pickingBank = false }, banks = d.accounts.map { it.brand })`. ## U-68

**Макет:** https://claude.ai/artifact/ApbasN6g8qD9J21zWMfcPP (исходник `docs/mockups/cycle-14/u68-deposit-return.html` + `mock.css`). Вкладки «Вклад уже есть» (4 кадра + «Проиграть»), «Вклад новый», «Пакет скринов», «Подсветка крупно».

### Решение
Один ответ на любой исход скана вклада: **возврат во «Вклады» → список доезжает до вклада → у карточки полоса подсветки → снекбар одной строкой.**
- Дубль (одиночный скрин): как только распознан дубль, экран «Проверьте вклад» уходит назад (как сейчас), список доезжает до существующего вклада, полоса, снекбар **«Такой вклад уже есть»** с действием **«Это другой»** — открывает «Проверьте вклад» с прочитанными полями, чтобы сохранить как новый (если `DepositMatch` ошибся).
- Новый (одиночный): после «Сохранить вклад» — доезжаем до нового вклада, полоса, снекбар **«Вклад добавлен»** без действия.
- Пакет: после «Сохранить» в «Проверьте вклады» подсвечены все вклады пакета (новые и найденные дубли), список доезжает до первого по порядку в списке; снекбар **«Добавили 2 вклада · 1 уже был»** (без дублей — «Добавили 3 вклада»; одни дубли — «3 вклада уже были»).
- Чем говорим — снекбаром (тот же `SnackbarHost` в `MainActivity`: `PanelTop`, `Fg`, действие `Brass2`), не шторкой: новость ничего не требует от человека, шторка остановила бы его ради неё.

### Подсветка — тот же приём, что в истории
`HistoryLine(highlighted)`: полоса `Brass2` 3 dp по левому краю строки во всю высоту, без заливки, появление `Motion.NORMAL` (`HistoryLine.kt:58,63`). Её выносим в общий модификатор и ставим и в `HistoryLine`, и в `DepositRow` — одна вещь, а не копия. У вклада полоса держится 3 с и гаснет за `Motion.FAST`.

### Время
скан → (дубль найден / «Сохранить») → сразу `popBackStack` (уход вправо, `Motion.NORMAL`) и одновременно `animateScrollTo` к карточке (`Motion.NORMAL`, `Calm`) → полоса проявляется (`NORMAL`) + снекбар (4 с) → через 3 с полоса гаснет (`FAST`). «Убрать анимации»: прокрутка мгновенная, полоса появляется и исчезает без перехода, ничто не ждёт анимации.

### Куда доезжать
Карточка встаёт в верхнюю треть видимого списка (`scrollState.animateScrollTo`, ограничено концом списка). Уже видна целиком — не прокручиваем. Вклад в свёрнутых «Завершённых» — группа раскрывается. При сортировке «По банкам» — то же, в группе банка.

### Из чего собрано
`DepositsSection` / `DepositRow` (`ui/deposits`), `HistoryLine` (`ui/common`), `UndoCenter` + `SnackbarHost` (`ui/common/Undo.kt`, `MainActivity`), `Motion`, токены `Slitok.Brass2`. Новое в `ui/common`:
- `fun Modifier.highlightBar(on: Boolean): Modifier` — полоса `Brass2` 3 dp во всю высоту слева, появление `Motion.tween(Motion.NORMAL)`, уход `Motion.tween(Motion.FAST)`; `HistoryLine` переходит на него (вид не меняется).
