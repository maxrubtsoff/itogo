Слиток — дизайн-система Itogo

Эталон для всех экранов приложения: цвета, шрифты, суммы, компоненты и правила поведения. Экран собирается только из того, что есть здесь. Нужного нет — сначала элемент добавляется сюда, потом на экран. Размеры в пикселях равны dp в приложении.

Принципы

Одна главная цифра

На экране одна-две крупные суммы, остальные тише или за раскрытием. Копейки тусклее рублей, в крупных суммах ещё и мельче. Если цифру можно не показывать — не показываем.

Цвет — только со смыслом

Латунь — главное действие и выбранное. Мята — доход и начисления. Коралл — опасное. Остальные суммы — обычным цветом текста. Одна величина везде одного цвета.

Один путь к действию

Каждое действие доступно одним способом. Долгое нажатие — только для быстрого действия, которого нет на поверхности.

Без поясняющих подписей

Если элементу нужна подпись «нажмите, чтобы…», элемент переделывается. Объяснения живут только в обучении.

Приложение решает само

Что можно определить автоматически, определяется автоматически. Человеку остаётся одно касание на исправление.

Ошибка — после попытки

Красное появляется только когда человек попробовал сохранить и что-то не так. Пустая форма спокойна.

Цвет ui/theme/Color.kt · Slitok

Одна тёмная тема. Значения не меняются, меняются правила применения изменено: латунь больше не красит суммы.

Переходы и поведение

Шкала движения U-55

БыстроFAST · 200
ОбычноNORMAL · 300
МедленноSLOW · 450

FAST — меню, метка, скрытие сумм, уход. NORMAL — экран, карточка, строка, показ сумм. SLOW — рост графика, скан по скрину. Кривая прихода — Motion.Calm, без отскока. Уход — на ступень быстрее прихода. Своих чисел в tween(…) нет: только Motion. Ошибка («нельзя», неверный код) трясёт элемент одинаково везде — errorShake; без анимаций стоит на месте.

Глубже — пролёт вправо B-41

Обзор
Счета

Новый экран въезжает справа. Назад — обратно влево. Вкладки нижней панели — в сторону вкладки. Всплытия и «вырастания» строки нет.

«Назад» — откуда пришёл B-37

Банки → банк → счёт → «Назад» = банк. Переход в глубину кладётся поверх, а не сбрасывает путь.

Вкладка — сверху B-36

С нижней панели вкладка открывается с начала. Повторное касание — сразу сверху, без прокрутки. «Назад» с деталей сохраняет место.

Листание разделов B-43

Пейджер во всю ширину, отступы внутри страницы, между страницами зазор 24–32. Страницы не «склеены».

Долгое нажатие U-45

Только быстрое действие, которого нет на поверхности: «учитывать в капитале», «удалить пополнение». Не дублирует карандаш или касание.

«Убрать анимации»

Системная настройка Android, учитывается в одном месте — Motion. Включена — переходы мгновенные, пыль неподвижна. Касание всегда срабатывает сразу, анимация не задерживает действие.

Распознавание (скан) новое ScanningThumb · ScanReveal

Один компонент на кэшбэк, вклад, одиночный скрин, пакет и обучение. Вариант «Распознавание 1» (F-34).

Искусство 25%Отели 5%Рестораны 5%

По миниатюре идёт полоса сканирования (Motion.SLOW, по кругу) со статусом «Читаем скрин». По окончании полоса гаснет (Motion.FAST), поля плавно встают снизу каскадом через Motion.STAGGER_MS — Modifier.cascade(index, play). Значения стоят на месте, не «вылетают». В пакете — то же по каждому скрину. Пока читается — вместо полей скелет.

Не задерживает результат. Скрин, уже прочитанный при открытии экрана, показывается сразу (play = false); результат сразу правится. С «Убрать анимации» — без полосы и подъёма, поля просто есть.

Шапка скрина новое ShotHeader

Над формой распознанного скрина — кэшбэк, вклад, пакеты — один и тот же элемент (U-53).

Статусы U-53

РаспознаноСверьте со скрином и сохраните
ПроверьтеНе прочиталось: дата закрытия

Читается — скрин стоит крупно под полосой сканирования («Читаем скрин»); прочитано — он сжимается на месте в эту панель (один AnimatedContent, Motion.NORMAL), форма под ним не подменяется. Касание по миниатюре открывает скрин целиком. «Не прочиталось» — серое, не красное; пустые поля формы видны сами, отдельной плашки «Проверьте» нет.

Обучение новое FingerPointer · TourHighlight

Обучение идёт на настоящих экранах с примерными данными (U-54), действия показывает «палец» и сами экраны (F-32).

«Палец» F-32

FingerPointer(target, pressed) — круглый курсор: идёт к точке за Motion.NORMAL (кривая Motion.Standard), нажимает за Motion.FAST — слегка садится. Без точки гаснет на месте. С «Убрать анимации» просто стоит, где сказано.

Подсветка цели B-48

FRAMED — окно в затемнении и латунная рамка.

DIM_ONLY — только затемнение, без рамки.

Цели во всю ширину — шторка и нижняя панель — подсвечиваются только затемнением: рамка по краю экрана обрезалась бы (B-48). Остальные цели — с рамкой. Это поле шага сценария (TourStep.highlight), а не решение экрана.

Сценарий и пауза F-32

Шаг сценария (TourStep) знает, что играет на экране (anim): касание «+», шторка, выбор скринов, скан, поля по очереди, отметка категории, смена баланса. После каждого действия — пауза с коротким комментарием: следующее действие само не начнётся, пока человек не нажмёт «Далее» (waitForRead). Есть «Ещё раз» и «Пропустить».

Песочница. Обучение читает примерные данные из памяти (TourSample) через те же ViewModel; в базу, настройки и копию ничего не пишется, по выходу — снова настоящие данные.
