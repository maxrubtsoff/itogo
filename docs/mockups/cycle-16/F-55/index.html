F-55 · Исправить ручной остаток из истории

История капитала → Валюта. Строка «Остаток изменили вручную» становится нажимаемой: признак — шеврон «›» в конце серой подписи (как у HistoryLine GO). Касание открывает шторку. Три варианта — по ряду кадров на каждый: строка → шторка (несколько счетов) → шторка (один счёт) → результат.
