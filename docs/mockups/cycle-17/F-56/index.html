F-56 · Сортировка в виджете кэшбэка

Три режима: по банку (по умолчанию в узком виде — группы с шапкой банка), по размеру, по названию. Glance умеет только касания (actionRunCallback), поэтому переключатель — элемент в шапке виджета; выбор сохраняется для каждого экземпляра виджета (по appWidgetId) и переживает перезапуск.
