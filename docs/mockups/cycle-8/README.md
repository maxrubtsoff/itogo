# Макеты цикла 8

Копия исходников холста [Макеты цикла 8](https://claude.ai/artifact/GyLY859SE3795FrTzRfuJz) — на случай, если холст недоступен. Главная версия — холст: правки и комментарии Максима делаются там; после изменений холста эта папка обновляется.

- `canvas.json` — раскладка: какой экран где стоит и как подписан (подписи — с номерами пунктов ТЗ).
- `slitok.css` — общие стили макетов по дизайн-системе «Слиток» (1 px = 1 dp).
- `*.dc.html` — по экрану на файл. Открываются в браузере как обычный HTML (без `support.js` холста — только разметка и стили).
