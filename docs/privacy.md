# Политика конфиденциальности Itogo

Редакция от 27 октября 2026 года.

## Коротко

Все данные хранятся только на вашем телефоне, база зашифрована. Приложение читает уведомления только тех банков, которые вы выбрали. В сеть оно ходит лишь за публичными курсами ЦБ РФ. Рекламы, аналитики и передачи данных третьим лицам нет.

## Какие данные обрабатываются

Операции, остатки по счетам, вклады, кэшбэк, подписки и скриншоты, которые вы сами передали приложению.

## Откуда берутся данные

- Из уведомлений банковских приложений, которые вы выбрали. Для этого нужен доступ к уведомлениям, его выдаёте вы в настройках Android и можете отозвать в любой момент.
- Со скриншотов, которые вы сами отправили в приложение.
- SMS приложение не читает.

## Где хранятся данные

Только на устройстве, в зашифрованной базе (SQLCipher). Ключ шифрования лежит в Android Keystore и не покидает телефон. Вход в приложение защищён кодом и отпечатком, если вы их включили.

## Сеть

Приложение обращается только на cbr.ru за публичными курсами валют. Никаких ваших данных в этих запросах нет. Других сетевых обращений нет.

## Распознавание скриншотов

Выполняется на телефоне, без интернета. Скриншоты никуда не отправляются.

## Резервная копия

Копия шифруется паролем, который задаёте вы. Она уходит только туда, куда вы отправите файл сами.

## Разрешения

- Доступ к уведомлениям: чтобы записывать операции и остатки из уведомлений выбранных банков.
- Интернет и состояние сети: чтобы загрузить курсы ЦБ РФ.
- Показ уведомлений: для собственных напоминаний приложения, включается по вашему желанию.

Список установленных приложений целиком приложение не запрашивает, оно проверяет только заранее объявленные банковские приложения.

## Удаление данных

Удалите приложение или очистите его данные в настройках Android: всё сотрётся с телефона. Больше нигде копий нет.

## Дети

Приложение не предназначено для детей и не собирает данные о них.

## Изменения политики

При изменениях здесь появится новая редакция с датой.
