# Развёртывание сервера

Пошагово, с нуля. Нужен VPS на Ubuntu 24.04 и бесплатный домен.
Весь сервер запускается одной командой через Docker.

---

## 1. Домен (бесплатно, 2 минуты)

Для HTTPS нужен домен, указывающий на IP сервера. Бесплатный способ — DuckDNS:

1. Открой **duckdns.org**, войди (Google/GitHub).
2. Придумай поддомен, например `bankagg` → получишь `bankagg.duckdns.org`.
3. Пока оставь вкладку открытой — IP впишешь после создания VPS (шаг 2).

## 2. Создать VPS

На Timeweb Cloud (или Reg.ru / Beget / Selectel):

1. Создай облачный сервер: **Ubuntu 24.04**, самый дешёвый тариф (1 CPU, 1 ГБ),
   регион в России.
2. Вход по паролю. Получишь **IP-адрес**, логин `root` и пароль.
3. Вернись в DuckDNS, впиши этот IP в поле `current ip` своего поддомена и нажми
   **update ip**.

## 3. Подключиться к серверу

С компьютера, в терминале (или через веб-консоль в панели хостинга):

```bash
ssh root@ВАШ_IP
```

Введи пароль, который дал хостинг.

## 4. Установить Docker

Скопируй и выполни одной командой:

```bash
curl -fsSL https://get.docker.com | sh
```

## 5. Загрузить сервер на VPS

Склонируй репозиторий (замени на свой, если форкал):

```bash
apt-get update && apt-get install -y git
git clone https://github.com/maxrubtsoff/bank-aggregator.git
cd bank-aggregator/server
```

## 6. Настроить .env

Создай файл настроек:

```bash
cp .env.example .env
nano .env
```

Заполни два значения:

- `API_TOKEN` — длинный случайный токен. Сгенерируй командой и вставь результат:
  ```bash
  openssl rand -hex 32
  ```
- `DOMAIN` — твой домен из шага 1, например `bankagg.duckdns.org`.

Сохрани: `Ctrl+O`, `Enter`, `Ctrl+X`.

**Запиши `API_TOKEN` — его нужно будет ввести в приложении.**

## 7. Запустить

```bash
docker compose up -d --build
```

Через минуту сервер поднимется, Caddy сам получит HTTPS-сертификат.

Проверь:

```bash
curl https://ВАШ_ДОМЕН/api/ping -H "Authorization: Bearer ВАШ_ТОКЕН"
```

Ответ `{"ok":true,...}` — значит работает.

## 8. Подключить приложение

В приложении: **Настройки → Сервер и синхронизация**:

- Адрес сервера: `https://ВАШ_ДОМЕН`
- Токен: тот самый `API_TOKEN`
- **Проверить связь** → должно быть «✓ Связь есть».

Готово. Теперь перехваченные уведомления уходят на сервер, а на экранах
«Обзор» и «Счета» появляются балансы.

---

## Обновление сервера

Когда в коде что-то поменяется:

```bash
cd ~/bank-aggregator && git pull
cd server && docker compose up -d --build
```

## Полезное

- Логи: `docker compose logs -f api`
- Остановить: `docker compose down`
- База данных лежит в `server/data/bankagg.db` (бэкап — просто скопировать файл).

## Безопасность

- После настройки смени пароль root (`passwd`) или перейди на вход по SSH-ключу.
- `API_TOKEN` держи в секрете: это ключ к твоим финансовым данным.
- Сервер слушает HTTPS только по твоему домену; порт 8000 наружу не открыт.
